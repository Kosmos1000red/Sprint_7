Sprint_7 — автотесты для API «Яндекс Самокат»

Здесь лежат автотесты, которые проверяют API учебного сервиса Яндекс Самокат:
https://qa-scooter.praktikum-services.ru/

Что проверяем

- Создание курьера (`POST /api/v1/courier`)
- Логин курьера (`POST /api/v1/courier/login`)
- Создание заказа (`POST /api/v1/orders`)
- Получение списка заказов (`GET /api/v1/orders`)

Для каждой ручки — свой класс с тестами в папке `tests/`.

Что где лежит

- `urls.py` — все адреса API в одном месте.
- `data.py` — шаблоны тестовых данных и тексты ответов API.
- `helpers.py` — функции, которые создают случайные логины и пароли.
- `methods/` — методы для работы с API (создание курьера, логин, заказ и т.д.).
- `tests/` — сами тесты. На каждую ручку — свой файл и класс.
- `conftest.py` — фикстуры: создают тестовые данные перед тестом и удаляют после.
